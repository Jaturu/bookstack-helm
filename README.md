# bookstack-helm

[![CI](https://github.com/Jaturu/bookstack-helm/actions/workflows/ci.yaml/badge.svg)](https://github.com/Jaturu/bookstack-helm/actions/workflows/ci.yaml) [![Security status](https://img.shields.io/endpoint?url=https://raw.githubusercontent.com/Jaturu/bookstack-helm/main/docs/security-status.json)](docs/security-status.md)

A Helm chart and container image for running [BookStack](https://www.bookstackapp.com/)
on Kubernetes: non-root, read-only root filesystems, and compatible with the
`restricted` Pod Security Standard.

| Component | Location | Published as |
|-----------|----------|--------------|
| Helm chart | [`charts/bookstack`](charts/bookstack) | Helm repository `https://jaturu.github.io/bookstack-helm` and `oci://ghcr.io/jaturu/charts/bookstack` |
| Container image (php-fpm) | [`image/`](image) | `ghcr.io/jaturu/bookstack:<BookStack version>` (amd64 + arm64) |

Each image platform is scanned (Grype + Trivy) before release, signed keyless
with cosign, and published with SBOM, scan reports and provenance; the OCI chart
is signed too. See [Supply chain](docs/supply-chain.md) and the weekly
[security status](docs/security-status.md).

## Quick start

```console
helm repo add bookstack https://jaturu.github.io/bookstack-helm
helm repo update
helm install wiki bookstack/bookstack \
  --namespace bookstack --create-namespace \
  --set bookstack.appUrl=https://wiki.example.com
```

Then expose it with an HTTPRoute or Ingress (see [Exposure](docs/exposure.md))
and sign in as `admin@admin.com` / `password`. Change both immediately.
For a production install, follow [Installing](docs/installing.md).

```
Makefile              Local build, lint and docs targets
```

## Development

The BookStack version is set in one place: `appVersion` in
`charts/bookstack/Chart.yaml`.

```console
make version      # BookStack version from Chart.yaml
make test         # lint + template unit tests + schema validation
make test-image   # build the image and run its contract tests
make test-install # end-to-end install on a throwaway kind cluster
make test-upgrade # install the latest published release, upgrade to this checkout
make scan         # the release vulnerability gates, locally
make lint         # helm lint
make docs         # regenerate charts/bookstack/README.md (needs helm-docs)
```

CI (`.github/workflows/ci.yaml`) runs the same tests and the vulnerability
gates on every pull request. Merging to `main` runs `release.yaml`, which
publishes the image when `image/` or `appVersion` changed, and the chart when
its `version` was bumped. `rescan.yaml` re-scans the published image weekly.
Dependabot keeps actions, base images and test tooling current.

`charts/bookstack/README.md` is generated. Edit `README.md.gotmpl` or the
`# --` comments in `values.yaml`, then run `make docs`.
